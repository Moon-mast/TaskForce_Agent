# Stock Deep Research — 股票深度调研技能集

一个给 AI 编程助手（ZCode / Claude Code 等）用的**股票投资调研技能集合**。

装上它之后，你只要对 AI 说一句"帮我研究一下贵州茅台"，它就能像一个专业投研团队一样干活：先问清楚你的需求，然后派出多个"研究员"分头查资料，最后交给你一份带引用来源的完整调研报告。

---

## 一、快速开始：只要会打字就能用

你不需要记任何命令。装好技能后，直接对 AI 说话就行：

### 场景 1：想研究一只股票

```
你：帮我研究一下贵州茅台 600519 值不值得投资
```

AI 会先问你几个问题（大概长这样）：

- 你的投资风格是？价值 / 成长 / 困境反转 / 红利
- 打算持有多久？半年内 / 半年到一年半 / 一年以上
- 最关心什么？护城河、财务质量、估值、管理层……（选 2-3 个）
- 风险偏好：保守 / 平衡 / 激进

你回答完，AI 会先给你一份"研究计划"确认，然后开始干活，最后在 `RESEARCH/STOCK_600519_贵州茅台/` 目录下生成完整报告。

### 场景 2：不想被问，直接要结果

```
你：按价值投资、长期持有、保守风格，帮我尽调腾讯控股 00700.HK
```

信息给全了，AI 就跳过提问直接开始研究。

### 场景 3：研究别的主题（跟股票无关）

```
你：帮我深度调研一下固态电池行业的现状和格局
```

AI 会走通用研究流程，同样产出带引用的报告。

### 场景 4：已经有一份报告，想检查靠不靠谱

```
你：帮我验证一下这份报告里的引用来源
```

AI 会逐条检查：有没有出处？出处是真的吗？来源权威吗？

## 二、最后你会得到什么

以股票调研为例，AI 会生成这样一个文件夹：

```
RESEARCH/STOCK_600519_贵州茅台/
├── README.md                  # 目录导航
├── 00_执行摘要.md              # ⭐ 最重要：信号灯评级 + 投资逻辑 + 监控清单
├── 01_公司事实底座.md          # 这家公司是干嘛的、怎么赚钱
├── 02_行业周期分析.md          # 行业现在是景气还是萧条
├── 03_业务拆解.md              # 哪块业务最赚钱
├── 04_财务质量.md              # 账上的利润是真金白银还是纸面富贵
├── 05_股权治理.md              # 管理层靠不靠谱、会不会坑股东
├── 06_市场分歧.md              # 看多和看空的人分别在吵什么
├── 07_估值与护城河.md          # 现在的价格贵不贵
├── Financial_Data/            # 财务数据表
├── Valuation/                 # 估值测算过程
├── Risk_Monitoring/           # 空头观点、黑天鹅、监控清单
└── sources/                   # 全部引用来源（带权威度评级）
```

其中执行摘要的核心是一个**信号灯评级**：

- 🟢🟢🟢 积极关注（基本面全面向好）
- 🟡🟡🟡 中性观望（多空因素交织）
- 🔴🔴 回避（存在重大风险）

> **注意**：AI 只做研究，**不给买卖建议、不预测股价**。信号灯是基于基本面的研究结论，不是荐股。投资有风险，决定要自己下。

## 三、仓库里有什么

```
skills/
├── stock-deep-research/     # ⭐ 一体化技能（推荐用这个，整合了下述全部 7 个）
└── 
    ├── stock-question-refiner/     # 只做"问需求 + 出研究指令"
    ├── question-refiner/           # 通用版的问题细化
    ├── stock-research-executor/    # 只做"执行 8 阶段股票尽调"
    ├── research-executor/          # 通用版的研究执行
    ├── got-controller/             # GoT 图控制（复杂主题的策略调度）
    ├── synthesizer/                # 把多个研究员的发现合并成一份报告
    └── citation-validator/         # 检查引用来源的真实性和权威性
```

### 新旧技能的关系

新技能 `stock-deep-research` = 旧 7 个技能的**合体升级版**：


|---|---|
| stock-question-refiner + question-refiner | 阶段 0：需求澄清（先问你问题） |
| stock-research-executor | 阶段 2：8 阶段尽调执行（主力干活环节） |
| research-executor | 通用主题的 7 阶段研究流程 |
| got-controller | 复杂主题的策略调度器（可选叠加） |
| synthesizer | 阶段 3：把各研究员的发现合并成报告 |
| citation-validator | 阶段 4：交稿前的引用质检 |

工作流一句话概括：

```
问清需求 → 生成研究指令 → 定计划 → 多个AI"研究员"并行查资料
→ 合并发现 → 引用质检 → 交报告
```

## 四、安装方法

技能就是一个文件夹，把它放到 AI 助手能识别的技能目录里即可：

```bash
# 复制到用户级技能目录（所有项目都能用）
cp -r skills/stock-deep-research ~/.agents/skills/

# 或者只给当前项目用
cp -r skills/stock-deep-research <你的项目>/.agents/skills/
```

装好后无需任何配置，正常对话即可自动触发。

## 五、几个常见问题

**Q：AI 会不会瞎编数据？**
不会轻易得逞。流程里有强制的引用质检环节：每个事实性声明必须注明来源（作者、日期、标题、链接），来源还要按 A-E 评级（A=年报和监管文件这类一手资料，E=论坛传闻这类不可靠内容）。可疑数据会被标记出来。

**Q：搜不到某只股票的信息怎么办？**
AI 不会就此罢休。它会换关键词、换数据源（巨潮资讯、港交所披露易、SEC、东方财富等）反复尝试，全部尝试都会记录在 `sources/search_attempts.md` 里。如果股票已退市或数据太少，也会产出一份"数据受限报告"，说明哪些能查到、哪些查不到、为什么。

**Q：研报要跑多久？**
取决于你在需求澄清时选的深度：快速扫描（约 30-60 分钟的活）、标准尽调（2-4 小时）、深度分析（4-8 小时）。AI 并行干活，实际等待时间通常短得多。

**Q：能预测股价吗？**
不能，也不做。这套框架只做基本面研究：生意好不好、财务实不实、价格贵不贵、风险在哪里。买卖决策和择时请自己做判断。
