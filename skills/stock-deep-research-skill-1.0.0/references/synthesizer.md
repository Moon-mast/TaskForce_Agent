# 多智能体结果综合手册

整合原 `synthesizer`。当多个研究 agent 完成任务（或 GoT Aggregate 操作后），用本模块把原始发现变成连贯报告。常在 GoT **Aggregate** 操作之后调用。

**好综合** = "研究说了什么、意味着什么、你应该怎么做"。
**坏综合** = "研究发现清单"。

## 综合五阶段

### 阶段 1：审查与组织
- 通读全部 agent 发现，识别共同主题
- 标注矛盾与差异
- 评估来源质量与可信度
- 相关发现分组（**按主题分组，不按 agent 分组**）

### 阶段 2：共识分级
| 级别 | 标准 |
|------|------|
| 强共识 | 3+ 个高质量来源支持 |
| 中度共识 | 2 个来源支持 |
| 弱共识 | 仅 1 个来源 |
| 无共识 | 矛盾未解决，需并列呈现 |

### 阶段 3：矛盾解决（四类）
| 类型 | 案例 | 处理 |
|------|------|------|
| A 数值差异 | 市场规模两个数字 | 查发布日期、方法论、统计口径；给出区间或解释差异 |
| B 因果分歧 | 观察研究 vs 实验 | 证据等级高的优先；表述用"证据提示"而非"证明" |
| C 时序变化 | 新旧数据打架 | 按趋势呈现；当前状态用较新数据 |
| D 范围差异 | 不同市场口径 | 双方都保留语境，说明条件差异 |

两个高质量来源冲突时：承认并存、解释为何不同、**不武断二选一**。

### 阶段 4：结构化综合
```markdown
# [研究主题]: 综合报告
## Executive Summary
## 1. Introduction
## 2. [主题1] — 共识发现
## 3. [主题2]
## 4. [含矛盾的主题] — 解决方案
## 5. Integrated Analysis
## 6. Gaps and Limitations
## 7. Conclusions and Recommendations
## References
```

### 阶段 5：质量增强
- [ ] 全部主要发现已纳入
- [ ] 矛盾被承认并处理
- [ ] 共识与少数观点清晰区分
- [ ] 引用完整保留且准确
- [ ] 叙述流逻辑连贯
- [ ] 洞察可行动，不只是摘要
- [ ] 不确定性与局限显式说明
- [ ] **不引入任何无来源支撑的新声明**

## 五种综合技巧

1. **主题归组**：按主题而非来源组织
2. **来源三角验证**：多个高质量来源收敛 → 置信度提升
3. **渐进披露**：基础概念 → 复杂分析，逐层建立理解
4. **对比综合**：并排对比用表格
5. **叙事弧**：历史主题按阶段演化追踪

## 典型综合模式

| 模式 | 结构 |
|------|------|
| 问题-方案 | 问题 → 现有做法 → 局限 → 新兴方案 → 建议 |
| 过去-现在-未来 | 历史背景 → 现状 → 新趋势 → 展望 → 战略含义 |
| 对比评估 | 选项概览 → 按标准对比 → 优劣 → 场景匹配 → 推荐框架 |
| 因果分析 | 现象描述 → 成因识别 → 机制 → 证据强度 → 干预点 |

## 挑战处理

| 挑战 | 对策 |
|------|------|
| 数据量过大 | 分层：执行摘要 → 主报告 → 附录 |
| 高质量来源冲突 | 双方并列 + 解释差异 + 不武断选择 |
| 重要主题来源弱 | 标"待验证"，表述为"初步"，不夸大确定性 |
| 研究缺口 | 明确未知项、说明难查原因、建议补充路径 |
| 综合中发现缺口 | 用 Agent 工具补充一轮定向研究 |

## 输出格式（按需选择）

1. **完整报告**：全部发现详述
2. **执行摘要**：1-2 页浓缩
3. **主题分析**：按主题组织
4. **对比矩阵**：并排对比表
5. **决策框架**：结构化决策指引

## 质量评分（0-10，目标 ≥ 8）

- 覆盖度（0-2）：重要发现全纳入？
- 连贯性（0-2）：逻辑流畅？
- 准确性（0-2）：引用保留、无新声明？
- 洞察力（0-2）：可行动，非流水账？
- 清晰度（0-2）：组织清晰易懂？

**产出落盘**：`full_report.md`、`executive_summary.md`、`synthesis_notes.md`。
