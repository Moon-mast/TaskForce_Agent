# 股票尽调 8 阶段执行手册（阶段 2 详细指令）

整合原 `stock-research-executor` 的 SKILL.md 与 phases.md。前置条件：已从阶段 0 获得完整结构化调研指令。

## 执行流程（8 步）

1. **验证指令**：检查最低要求（代码、市场、风格、周期、范围、输出要求、约束），缺失则追问，不做假设
2. **创建执行计划**：阶段优先级排序 → 智能体部署矩阵 → 输出文件清单 → 呈现用户确认（自动化模式可短暂停顿后继续）
3. **并行部署**（阶段 1-7）：每阶段 4 个 agent 单条消息并行启动
4. **协调综合**：汇总发现 → 识别重叠 → 按来源质量解决矛盾 → 保留来源归属 → 形成连贯叙述
5. **生成阶段报告**：每阶段一个文件，用统一模板
6. **质量保证**：引用验证 + 交叉验证 + 完整性 + 客观性检查
7. **最终综合**：执行摘要 + 信号灯评级 + 全部产出文件
8. **引用验证**：按 references/citation-validator.md 完成最后一道防线

## 8 阶段总览与智能体矩阵（4 agent/阶段，共 28 个）

## 阶段 1：公司事实底座（Business Foundation）

**目标**：公司做什么、怎么赚钱、在价值链的位置。

**Agent 1A 核心业务与产品**：产品/服务组合、业务分部、各分部盈利模式、营收占比、产品生命周期阶段。来源：年报业务概览、公司官网、投资者演示、分部报告。

**Agent 1B 营收利润构成**：各分部/产品/地区营收拆分、分部毛利率、分部经营利润、3-5 年趋势、高收入低利润分部识别。来源：年报分部报告、财报附注、管理层纪要。

**Agent 1C 客户与价值链**：客户细分（B2B/B2C、行业、地域）、前 5/10 大客户集中度、渠道结构（直销/经销/线上）、价值链位置与议价能力。来源：年报、行业报告、投资者演示。

**Agent 1D 近期战略变化**：3-5 年重大并购/剥离、新品发布/停产、市场进退、战略合资、组织重组。来源：近 3-5 年年报 MD&A、公告、新闻档案。

**输出模板（01_Business_Foundation.md）**：
```markdown
# Phase 1: Business Foundation
## Executive Summary
[2-3 段概览]
## 1.1 核心业务与产品
[业务模式一句话 + 分部表格: Segment | Description | Revenue | % | Growth Trend]
## 1.2 营收利润构成
[营收结构表 + 分部利润率表 + 关键洞察（最赚钱分部、错配项）]
## 1.3 客户与价值链
[客户细分表 + 集中度风险 + 价值链位置/议价能力 + 渠道结构]
## 1.4 近期战略变化
[事件时间线表: Year | Event | Impact | Status + 战略一致性评估]
## Key Takeaways
[3-5 条最重要洞察]
## Red Flags Identified
[需要进一步调查的发现]
## Sources
[全部来源 + A-E 评级]
```

## 阶段 2：行业周期分析（Industry Analysis）

**目标**：行业所处周期、供需、竞争格局、外部变量。

**Agent 2A 周期位置**：判断复苏/扩张/衰退/收缩；证据链（产能利用率、库存、价格趋势、CapEx）；当前阶段持续时长、历史周期长度、拐点触发因素；领先与滞后指标。来源：行业协会、统计局、咨询报告（需一手源验证）、管理层展望。

**Agent 2B 供需动态**：需求驱动（长期/周期/政策分类，强度与趋势）、供给产能与利用率、未来新增产能、进出口、订单/交付周期、12-24 个月平衡展望。来源：行业报告、公司披露、贸易数据。

**Agent 2C 竞争格局**：主要对手与市占率、市场结构（分散/寡头/垄断）、CR5/CR10、竞争维度（价格/质量/创新/品牌）与强度、并购整合趋势、进入壁垒（资本/监管/技术/品牌）与退出壁垒。来源：行业报告、年报竞争格局章节、反垄断文件。

**Agent 2D 政策与外部变量**：政府政策（补贴/税收/监管，方向与时间表）、宏观敏感性（利率/汇率/通胀/大宗）、技术颠覆、ESG 与社会趋势、地缘风险、结构性 vs 周期性因素区分。来源：政府网站、监管文件、行业协会、新闻。

**输出（02_Industry_Analysis.md）**：周期位置+证据表、供需展望、竞争地图、外部风险评估、基于周期位置的投资含义。

## 阶段 3：业务拆解（Business Breakdown）

**目标**：颗粒度上理解赚钱经济学。

**Agent 3A 分部深挖**：各分部营收/增速/毛利率/经营利润率/ROIC（5 年史）、分部 CapEx、内部交易与转移定价、交叉补贴识别（盈利分部养亏损分部）。核心产出：核心利润引擎、隐藏亮点、拖累项。

**Agent 3B 利润引擎**：**一句话业务本质**（卖什么→卖给谁→凭什么收溢价/有成本优势）；成本结构（固定/变动的占比与趋势）；规模经济证据；新增收入的边际利润率；提价能力与客户价格敏感度。

**Agent 3C 客户与定价**：客户留存/流失率、获客 vs 留存成本、粘性因素（转换成本/合同期/续约率/满意度）、历史调价记录、价格 vs 竞对（溢价/平价/折价）、定价机制（市场驱动/成本加成/价值定价）。

**Agent 3D 子公司与非经常项**：主要子公司/联营公司清单与贡献、投资收益/资产出售/政府补贴占净利润比重与可持续性、隐藏资产与隐藏负债、剔除非经常项后的真实核心利润。

**输出（03_Business_Breakdown.md）**：业务本质一句话、分部盈利矩阵、客户经济学总结、可持续利润 vs 不可持续利润评估。

## 阶段 4：财务质量（Financial Quality）

**目标**：盈利质量、财务健康、红旗识别。

**Agent 4A 关键指标趋势**（5-10 年）：营收/净利/经营利润 CAGR（3/5/10 年）；毛利率/经营利润率/净利率/ROE/ROIC 现值与均值趋势；**杜邦分解**（净利率 × 资产周转 × 杠杆，定位 ROE 变化驱动）；关键拐点标注。

**Agent 4B 现金流质量**：5-10 年 OCF、FCF、OCF/NI、FCF/NI 对照表。判定标准：**>1.0 优秀；0.8-1.0 良好；0.5-0.8 关注（应计项目大）；<0.5 红旗（利润未变现）**。红旗：OCF 持续低于净利、比率恶化、营运资本剧烈波动、CapEx 侵蚀现金流。FCF 用途拆解（维持性/成长性 CapEx、分红、回购、并购、还债）与可持续分红/回购能力判定。

**Agent 4C 异常筛查**：应收/存货增速 vs 营收增速（连续 3 年对比，显著偏离即关注）；DSO 变化；非经常项频率与金额；会计政策变更/重述；关联交易；审计意见；表外项目。**资产负债表应计分析**：Accruals = (Δ流动资产-Δ现金) - (Δ流动负债-Δ短期借款)，高应计提示盈利质量低。

**Agent 4D 同业对比**：3-5 家可比公司，对比增速/利润率/ROE/ROIC/估值倍数；标注公司排名；显著偏离项必须解释（商业模式差异 vs 真实优劣）。

**输出（04_Financial_Quality.md）**：财务健康总评（优/良/中/差）、现金流质量结论、红旗汇总表、同业排名表。

## 阶段 5：股权治理（Governance Analysis）

**目标**：管理层可信度与资本配置能力。

- **Agent 5A 股权结构**：控股股东与实际控制人、股权集中度、国资/外资/创始团队属性、一致行动人、股权质押率
- **Agent 5B 管理层与激励**：核心管理层背景与任期、薪酬结构（与业绩挂钩程度）、股权激励计划（行权条件 vs 实际达成）、高管增减持记录、关键人风险
- **Agent 5C 资本配置记录**：历史上并购的成败与商誉减值、CapEx 投向与回报（ROIC 趋势验证）、多元化 vs 聚焦、回购/分红时机（高位扩张低位回购 = 反面教材）
- **Agent 5D 股东回报与解禁**：分红政策与实际执行、回购金额与注销比例、限售股解禁时间表、大股东减持计划、增发摊薄历史

**输出（05_Governance_Analysis.md）**：治理评级、资本配置记分卡、股东回报记录、利益输送/侵害中小股东风险点。

## 阶段 6：市场分歧（Market Sentiment）

**目标**：多空双方的逻辑与决定性数据。

- **Agent 6A 多头案例**：市场看多的核心论据、目标逻辑链、依赖的关键假设
- **Agent 6B 空头案例**：看空论据、做空机构观点（如有）、失败场景叙事
- **Agent 6C 关键分歧点**：多空分歧最大的 3-5 个问题（如"增速可持续吗""提价空间还有吗"），双方各自证据
- **Agent 6D 验证节点**：什么数据/事件/财报指标会裁决上述分歧（如"下季度毛利率回升则空头定价权论被证伪"），给出可观察的时间表

**输出（06_Market_Sentiment.md）**：多空论据对照表、分歧清单 + 每项的裁决数据、情绪指标（分析师评级分布、目标价区间、融资余额/做空比例——如可得）。

**数据源注意**：新闻与社交媒体仅用于本阶段，且需事实核查后引用。

## 阶段 7：估值与护城河（Valuation & Moat）

**目标**：竞争优势强度与估值区间。

- **Agent 7A 护城河评估**：0-5 分评级，分五维打分并附证据——定价权、转换成本、网络效应、成本优势、无形资产（品牌/专利/牌照）
- **Agent 7B 相对估值**：PE/PB/PS/EV/EBITDA 的历史分位（5-10 年）+ 同业对比矩阵；识别溢价/折价及合理性
- **Agent 7C 绝对估值**：DCF 三情景（保守/基准/乐观，列明全部假设）；**反推 DCF**——当前股价隐含的增长率与回报率，判断市场预期是否现实；分部估值（多业务集团）/ 清算价值（困境股）按需
- **Agent 7D 风险场景**：3-5 个失败场景（需求萎缩/价格战/政策打击/技术替代/财务暴雷），各评估概率×影响，给出黑天鹅清单与监控阈值

**输出（07_Valuation_Moat.md）**：护城河五维雷达（分数+证据）、估值区间汇总表（方法 | 悲观 | 中性 | 乐观 | 当前价位置）、隐含预期分析、风险场景矩阵。

## 阶段 8：综合报告（Final Synthesis）

汇总 1-7 阶段全部报告，产出执行摘要。**结构**：

## 投资风格特殊调整

| 风格 | 侧重 | 估值方法 | 专项红旗 |
|------|------|---------|---------|
| 价值 | 资产负债表实力、正常化盈利、安全边际 | P/B、EV/EBITDA、保守 DCF | 生意质量恶化、价值陷阱、会计问题 |
| 成长 | TAM、竞争卡位、成长可持续 | PEG、成长 DCF、单用户价值 | 增速放缓、竞争威胁、估值压缩 |
| 困境反转 | 流动性、偿付能力、重组进展 | 清算价值、期权价值、回收情景 | 资不抵债、无生存路径 |
| 红利 | 股息可持续、派息率、FCF 创造 | DDM、股息率 vs 替代品 | 削减分红、派息率过高、FCF 下滑 |

## 特殊场景调整

- **困境公司（破产风险）**：强化阶段 4（偿付）与 7（清算价值）；增加"持续经营 vs 清算"分析；估值用概率加权回收情景；强调二元结果与时间风险
- **高成长未盈利**：阶段 4 聚焦现金消耗率、跑道、盈利路径；估值用单用户价值/TAM 渗透；跳过传统 PE/DCF；增加成长可持续性与护城河耐久性评估
- **次新股（IPO）**：阶段 1 以招股书为核心；阶段 4 用招股书财务数据；阶段 5 查锁定期到期与内部人减持计划；估值难（无交易历史），聚焦招股指引
- **跨市场公司（如 A 股）**：数据源侧重当地语言（中文）；提供双语或说明翻译来源；纳入国别监管风险；注明会计准则（IFRS/US GAAP/CAS）
