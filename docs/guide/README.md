## 写作约定(新专题请沿用)

1. **按层次拆文件, 不写大杂烩**: 一个文件讲一层, 250~600 行, 主题单一; 篇间用相对链接 + `§x.x` 交叉引用。
2. **每篇头部一段引用块**: `> 一句话: … | 对应实现: <文件/包> | 前置: <篇> | 下游: <篇> | 证据: <报告/测试>`。
3. **数字必须可追溯**: 每个指标都要写清来源(哪份报告、多少题、什么参数快照), 不允许出现孤零零无法验证的数字。
4. **引用而非复制**: 方案论证链回 `docs/new_module/`, 契约归属链回 [ROADMAP §6/§7](../dev/ROADMAP.md), 术语一律用 [CONTEXT.md](../../CONTEXT.md) 的口径, 不新造词。
5. **图只画两张类型**: 端到端流程/数据流用 ` ```mermaid `; 模块依赖用 ` ```text ` ASCII 箭头图。
6. **代码只给锚点**: 签名 + 关键行 + `文件:行号`, 不粘贴大段源码。
7. **中文正文用半角逗号 + 空格** `, `(与 `docs/new_module/` 系列一致), 字段名与代码标识保留英文原样。
