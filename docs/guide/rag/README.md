# RAG 知识库 · 专题总览

> 一句话: 这个专题用两套文档讲同一件事 —— `rag_v01/` 讲**系统怎么跑、为什么这么设计**, `interview/` 讲**被追问时怎么答**。
> 对应实现: `src/rag_v01/`(内核) + `src/tools/rag/kb_search.py`(agent 侧适配层) + `src/agent/subagents/retriever.py`(检索子智能体)
> 上游: [../README.md](../README.md)(guide 类目) | 方案与进度: [../../new_module/rag_0.1/TODO.md](../../new_module/rag_0.1/TODO.md) | 契约登记: [ROADMAP §6/§7](../../dev/ROADMAP.md)

## 一、两个系列各自解决什么

| 系列 | 目录 | 读者问题 | 组织方式 |
|---|---|---|---|
| **全链路讲解** | [rag_v01/](./rag_v01/00-全链路总览.md) | "这条链子怎么跑通的? 每个选择为什么?" | 按数据流分层: 入库 → 检索 → 生成 → 检验; 再加细节手册与调参手册 |
| **面试拷打** | [interview/](./interview/01-检索与分块.md) | "面试官连问三层, 我答得出来吗?" | 按追问域分文件: 每题含答题骨架 / 深挖追问 / 证据锚点 / 常见错误答法 |

两套文档**共享同一批证据**: 讲解篇里给的每个数字与 `文件:行号`, 面试篇的"证据锚点"直接复用。所以改动实现后要同时回填两处。
